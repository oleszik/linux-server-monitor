# Linux Server Monitor

## Goal
Build a lightweight Linux monitoring application that detects common resource, service and Docker problems and produces useful alerts instead of requiring constant manual checking.

## Planned features
- CPU/load, RAM/swap and disk monitoring
- Temperature and network checks
- systemd service checks
- Docker container health/status
- Configurable thresholds
- Structured logging and event history
- Optional email/webhook notifications
- Dockerized deployment and automated tests

## Portfolio objective
Demonstrate Python, Linux administration, system monitoring, Docker, automation, logging and troubleshooting.

## Status
Planning / initial development.
